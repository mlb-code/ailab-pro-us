# משימות של מאיר (AI Lab Pro US)

## 0. קודם: חוות דעת שנייה מ-Perplexity (11.10.2026)
להדביק ב-Perplexity את הפרומפט שקיבלת בצ'אט, ולהדביק את התשובה חזרה לקלוד. רק אחרי זה ממשיכים לסעיפים 1–4. אם Perplexity סותר משהו מהותי (מחירים, רישום SMS, Twilio לעסק ישראלי, תשלומים), מתקנים את המפרט לפני שקונים דומיין.

## 1. ✅ בוצע 11.10: הדומיין `ailabpro.co` נקנה ב-Cloudflare ($30 לשנה)
dash.cloudflare.com → בתפריט השמאלי **Domain Registration** → **Register Domains** → להקליד `ailabpro.co` → Purchase → לשלם.
✅ הצלחה: הדומיין מופיע ברשימת האתרים שלך ב-Cloudflare.

## 2. תיבת מייל בדומיין (חינם, ההודעות מגיעות לג'ימייל)
Cloudflare → לוחצים על `ailabpro.co` → **Email** → **Email Routing** → Get started → Custom address: `hello` → Destination: `laviemb@gmail.com` → Create. יגיע מייל אימות לג'ימייל, לאשר.
✅ הצלחה: `hello@ailabpro.co` מופיע עם סטטוס Active.

## 3. חשבון Supabase חדש (רק אתה יכול לפתוח)
supabase.com → Sign up → **Sign up with email** (לא Google): `hello@ailabpro.co` + סיסמה חדשה → מייל אימות יגיע לג'ימייל → לאשר. אם Supabase יוצר אוטומטית ארגון ופרויקט ריק, לא לגעת.
✅ הצלחה: אתה בתוך הדשבורד עם הכתובת החדשה.

## 4. טוקן לסוכן הבנייה
בתוך Supabase: האייקון שלך למטה משמאל → **Account preferences** → **Access Tokens** → Generate new token → שם `us-setup` → Generate → להעתיק (מוצג פעם אחת).
לפתוח את `~/Desktop/ailab-pro-us/.secrets.env` ולהדביק אחרי `SUPABASE_ACCESS_TOKEN=`. לשמור.
✅ הצלחה: השורה מתחילה ב-`SUPABASE_ACCESS_TOKEN=sbp_`.
באותו קובץ אפשר כבר להדביק גם את מפתח Claude אחרי `ANTHROPIC_API_KEY=`.

כשהכול בוצע: לכתוב לקלוד "בוצע 1–4". סוכן יקים את מסד הנתונים `ailab-us` ויחבר.
