# B1 — שלד ה-runtime + ליבת הסימולטור (11.10.2026, עודכן אחרי ביקורת)

**נבנה:** `runtime/pyproject.toml` (Python 3.12), `railway.toml`, venv ב-`runtime/.venv` (מוחרג מ-git).
- `app/settings.py`: מצבי `prod`/`sim`; ב-prod בלי `TWILIO_AUTH_TOKEN` כל webhook מקבל 503. המודל ושם המותג נקראים מ-`app/brand.json` (fallback ל-`config/brand.json`), בלי ערכים קשיחים.
- `app/twilio_auth.py`: אימות `X-Twilio-Signature` על `/voice/*`, `/sms/*` בכל המצבים, גם בסימולטור.
- `app/tenants.py` + `tenant_schema.json` (נוצר מהמודל, עם בדיקת drift): נישות `home_services`/`real_estate`/`dental` (בדיקה שזהות ל-`brand.json`), ושדה `trade`. השגיאות קריאות.
- `app/store.py`: `JsonStore` ו-`SupabaseStore` מאחורי ממשק אחד, עם **`store.for_tenant(id)`** שמחייב tenant בכל select/insert/update/delete (בדיקת A/B על שני ה-adapters). מחיקה בלי פילטר נדחית בשניהם. `StateStore` (טבלה `runtime_state`) עם fallback לזיכרון רק ב-sim. לוגי httpx/httpx2 מושתקים.
- `app/crypto.py` (AES-256-GCM + HMAC state), `app/main.py` (`/health`, ניתוב לפי `To`, stubs ל-voice/sms).
- `sim/`: Twilio מדומה (חתימה, TwiML, REST, Lookup), יומן SQLite, replay, harness, `demo-hvac.json`, CLI: `serve | selftest | validate | call | sms | run | record`.

**בדיקות (מתוך `runtime/`):** `.venv/bin/python -m pytest -q` → `233 passed` (כיסוי `app` 98% לפי ענפים) · `python -m sim selftest` → `11/11` · `check_hardcoded runtime` → 0 שגיאות, `check_secrets runtime` → 0 ממצאים.

**לא ממומש / פתוח:**
1. **הבידוד בין tenants נאכף בקוד ה-runtime** (`TenantStore`), כי ה-service role עוקף RLS. קוד שקורא ישירות ל-`store.select/update` עוקף אותו. הקריאות הישירות היחידות כרגע הן חיפוש tenant לפי מספר, setup ובדיקות.
2. A1 צריך להוסיף: טבלה `runtime_state` (key, tenant_id, value jsonb, updated_at), RPC `runtime_get_credential`/`runtime_put_credential`, `public.ping()`. בלי אלה, `SupabaseStore` נכשל ב-prod (בכוונה, בלי fallback).
3. `/voice/*` ו-`/sms/*` הם stubs; הזרימות המלאות שייכות ל-B3/B4. דף `/sim` בדפדפן לא נבנה.
4. לא הורצה פקודת git (לפי הוראה). הקבצים ממתינים ל-commit.
5. `make qa-static` נכשל רק על `site/start/assets/{home,q}.js` (שמות אירועי analytics, עבודה של A5), לא על runtime.
