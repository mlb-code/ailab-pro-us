# פרסום אוטומטי לעמוד הפייסבוק האמריקאי (AI Lab Pro)

## מה זה עושה
- יש "בנק" של 30 פוסטים באנגלית (`social/bank/posts.json`), כל אחד עם תמונה (`social/bank/img/`).
- כל יום ב-11:00 בבוקר שעון ניו יורק (18:00 בישראל) GitHub מריץ את `social/fb_post.py`.
- הסקריפט בודק בעמוד: אם הפוסט האחרון בעמוד ישן מ-9 שעות, הוא מפרסם את הפוסט הבא מהבנק. אחרת הוא לא עושה כלום.
- התוצאה: **פוסט אחד כל יום**. 30 פוסטים = בערך חודשיים.
- הסקריפט יודע מה כבר פורסם לפי 60 התווים הראשונים של כל פוסט. גם פוסט שתפרסם ידנית "מאפס את השעון" ל-9 שעות.

## מה מתפרסם
טיפים לבעלי עסקים (שיחות שלא נענו, אחרי שעות, הודעות חזרה, קביעת תורים), נתונים עם מקור כתוב בפוסט, "איך זה עובד", שאלות נפוצות, מחירים (מחיר קבוע, מחיר לקוח מייסד, ערבות 30 יום, חבילה) ואתרים.
הרשימה המלאה לאישור: `social/bank/approval.he.md`.

## המערכת אף פעם לא ממציאה ביקורות
אין בבנק ביקורות, המלצות, שמות לקוחות, לוגואים או "כמה לקוחות יש לנו". זה אסור לפי כללי ה-FTC האמריקאיים.
בדיקה אוטומטית (`make social-check`) חוסמת מילים כמו "guaranteed", "HIPAA", "compliant" ומחירים שלא מופיעים במחירון.

## איך לעצור (השהיה)
אחת משתיים, בדפדפן:
1. GitHub → הריפו `ailab-pro-us` → **Settings** → **Secrets and variables** → **Actions** → לשונית **Variables** → `SOCIAL_FB_ENABLED` → לשנות ל-`false`.
2. או: GitHub → **Actions** → בצד שמאל `social-fb` → למעלה מימין `⋯` → **Disable workflow**.
להפעלה מחדש: להחזיר ל-`true` / **Enable workflow**.

## איך להחליף פוסט
- **לדלג על פוסט**: בקובץ `posts.json`, להוסיף לפוסט את השורה `"skip": true,` — הוא לא יתפרסם.
- **להחליף טקסט**: לשנות את `message` של פוסט שעוד **לא** פורסם. (לא לשנות פוסט שכבר פורסם: המערכת תחשוב שהוא חדש ותפרסם שוב.)
- **להחליף תמונה**: לשנות את `card` (כותרת, מספר גדול, שורה קטנה) ולהריץ `make social-cards`.
- אחרי כל שינוי: `make social-check` (צריך לצאת `0 errors`).
- הכי פשוט: לכתוב לי "תחליף את פוסט 12" ואני עושה הכול.

## להוסיף ביקורות אמיתיות (בעתיד)
כשיהיה לקוח אמיתי שכתב ביקורת (בגוגל, בפייסבוק וכו'):
1. מדביקים אותה ב-`site/_content/reviews.json` (שם, עסק, עיר, טקסט, קישור לביקורת המקורית, תאריך, `"consent": true` = הלקוח הסכים). מדור "What clients say" באתר מופיע רק כשיש **לפחות 2** ביקורות כאלה; עד אז אין באתר מדור ביקורות בכלל (ואין כרטיסים ריקים), רק השיחות לדוגמה "What a call sounds like".
2. מוסיפים לבנק פוסט מסוג `"kind": "review"` שמצטט אותה **מילה במילה**, עם הקישור למקור.
3. רק ביקורת שלקוח אמיתי כתב. אין "ביקורות לדוגמה" בפייסבוק.

## בדיקות שאפשר להריץ (מהטרמינל, בתיקיית הריפו)
- `make social-status` — טבלה: מה פורסם ומה לא. קורא מהעמוד, **לא מפרסם**.
- `make social-dry` — מה היה מתפרסם עכשיו. **לא מפרסם**.
- הרצה ידנית ב-GitHub: Actions → `social-fb` → **Run workflow**. ברירת המחדל היא Dry run (לא מפרסם). רק אם מורידים את הסימון ב-Dry run הוא מפרסם.

## הפעלה ראשונה (פעם אחת)
1. ב-GitHub: Settings → Secrets and variables → Actions → **New repository secret**: שם `META_ACCESS_TOKEN`, ערך: הטוקן מ-`meta-ads/.env`.
2. לשונית **Variables** → **New repository variable**: שם `SOCIAL_FB_ENABLED`, ערך `true`.
עד ששני אלה לא קיימים, שום דבר לא מתפרסם.
